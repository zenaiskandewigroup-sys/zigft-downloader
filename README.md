# ZIGFT Downloader

A simple YouTube Audio Downloader built using Python, Flask, and yt-dlp.

## Features

- Download YouTube audio
- Convert automatically to MP3
- Bootstrap UI
- Download progress
- Auto delete downloaded files
- Fast and lightweight

## Technologies

- Python
- Flask
- yt-dlp
- FFmpeg
- Bootstrap

## Run

Install dependencies

```bash
pip install -r requirements.txt
```

Run application

```bash
python downloader.py
```

Open browser

```
http://localhost:7070
```
